## About Me

I'm a **Computer Science student at Manuel S. Enverga University Foundation** with a strong interest in software engineering, artificial intelligence, and full-stack development.

I enjoy working across the stack—from designing user interfaces and backend systems to working with databases and intelligent applications.

My focus is on writing software that is:

* **Reliable** — designed with maintainability and scalability in mind
* **Practical** — built to solve real problems
* **Intuitive** — focused on clean and responsive user experiences
* **Intelligent** — leveraging AI where it genuinely adds value

I'm continuously learning, experimenting, and building projects that turn ideas into working systems.
